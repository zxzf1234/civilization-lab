# 经济兴衰的规律

## 核心问题

经济体为什么增长、繁荣、停滞或陷入危机？短期商业周期与长期兴衰有什么区别和联系？

## 分析维度

- 技术、能源与生产率。
- 人口、教育与劳动力结构。
- 制度、产权、市场与国家能力。
- 财政、货币、信用与债务。
- 产业、贸易、资源与国际分工。
- 分配、社会稳定与政治反馈。

## 待讨论

- 如何区分周期波动、结构转型和长期衰退？
- 增长的必要条件和充分条件分别是什么？
- 金融危机何时会转化为政治或制度危机？
- 后发经济体为何能够追赶，又为何会掉入停滞？
