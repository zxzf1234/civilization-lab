# 国家兴衰的规律

## 核心问题

国家为什么崛起、维持繁荣、停滞、衰退或瓦解？这些过程是否存在跨时代的共同机制？

## 分析维度

- 政治：国家能力、制度适应、合法性、精英竞争。
- 经济：财政基础、生产力、分配、债务与贸易。
- 地理：资源、边疆、交通、气候与战略位置。
- 文化与宗教：认同、信任、规范、动员与权威。
- 外部环境：战争、技术扩散、国际体系与竞争者。

## 待讨论

- “兴衰”应如何定义和衡量？
- 帝国、民族国家、城邦是否能放在同一框架内比较？
- 内部制度与外部冲击分别起多大作用？
- 衰退是绝对倒退，还是相对其他国家落后？

## 当前分析框架

“灭亡原因”暂按主导机制分为三类：

1. **外力主导型**：政权在受到进攻前仍有基本统治能力，强大外敌的征服是不可缺少的主要原因。
2. **内崩主导型**：财政、行政、合法性或内部战争已经使政权接近失去维持能力，外敌不是必要条件或主要只起加速作用。
3. **内外结合型**：内部衰弱显著改变了战争胜负，而外部进攻完成政权灭亡，二者都不能降为次要背景。

这三类不是非黑即白的标签，而是一条连续尺度。判断时至少追问：

- 没有这次外敌进攻，政权是否很可能在相近时间自行崩溃？
- 若换成较弱的外敌，现有内部问题是否仍足以导致灭亡？
- 内部因素只是长期弱点，还是已经直接破坏了财政、指挥、动员与统治？
- 外敌是否通过吸收人口、技术、军队和地方合作者，在战争中继续增强？

还应区分：**王朝或政权灭亡、国家机器解体、社会与文明衰落**。三者可能同时发生，也可能彼此分离。

### 规模不对称假设

当前提出一个待检验假设：**在领土兼并较常见、缺少国际保护机制的时代，小国或相对弱国更容易被强邻消灭。**这里的关键变量不是国土面积本身，而是与潜在征服者相比的“有效战争规模”，包括可动员人口、财政、军事组织、技术、战略纵深、联盟和补充损失的能力。

可能的机制是：

```text
长期力量不对称
＋ 缺少可靠盟友、缓冲区或国际规则保护
→ 强国预期征服收益高于成本
→ 小国难以补充战争损失
→ 战败、附庸化或被兼并
```

该假设不等于“小国必亡”。地形、防御技术、外交结盟、强国间制衡以及征服成本都可能使小国长期存续。现代国际体系中的领土完整规范、集体安全和威慑也可能降低小国被直接兼并的概率。因此需要分别研究古代多国体系与现代主权国家体系。

## 阶段性结论

现阶段更适合研究反复出现的因果机制，而不是预设存在固定长度的普遍周期。外部征服可以独立造成一个仍有治理能力的政权灭亡；内部弱点则可能改变抵抗成本、持续时间与最终胜负。二者的相对权重需要逐案判断。

宋代初步比较显示，北宋与南宋都不能仅用“积贫积弱”概括：北宋之亡暂归为**内外结合、外力触发**；南宋之亡暂归为**外力主导、内部与战争过程因素辅助**。详见[北宋与南宋灭亡的内外因素](../../cases/song-conquests-northern-and-southern.md)。这一判断为研究中结论，信心水平中等。

关于规模不对称、扩张帝国累积优势及小国存续条件的可复用机制，见[外部征服、力量不对称与国家存续](../../domains/military/external-conquest-and-state-survival.md)。

## 待研究问题

- 用同一标准比较明、罗马、拜占庭等案例，检验三分法是否有效。
- 寻找面对强敌但成功存续的反例，识别地理、联盟和制度适应的作用。
- 区分“开战前已有的内部衰弱”与“长期战争造成的内部瓦解”。
- 比较格拉纳达、晚期拜占庭、琉球等相对较小政权，检验规模不对称假设；同时避免把内部争斗和长期衰退遗漏掉。
- 选择越南抵抗蒙古等小国成功存续的反例，研究地形、后勤、联盟和征服收益的作用。
