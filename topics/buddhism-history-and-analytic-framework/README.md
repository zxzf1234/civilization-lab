# 佛教的历史演变与分析框架

## 核心问题

1. 佛教从早期印度教团发展到当代各地传统，经历了哪些关键分化、传播与重组？
2. 不同宗派、思想学派、戒律传承和地域传统之间是什么关系，各自强调哪些核心思想与实践？
3. 能否借助现代学科，把佛教中的神话、哲学、心理、伦理、仪式、组织与政治经济等层面分析性地拆开？
4. 拆分以后，如何避免把现代分类误当成佛教自身原有的边界？

## 概念界定

- “佛教”暂指围绕佛、法、僧以及解脱道路形成，后来在南亚、东南亚、中亚、东亚、喜马拉雅地区和现代全球社会中持续重构的一组传统，而非固定不变的单一体系。
- “宗派”是暂用词。研究时需区分：早期部派、哲学学派、戒律传承、修行法门、师承谱系、地域佛教与现代宗教组织。
- “拆分”是分析工具，不主张神话、哲学、心理和实践在历史上彼此独立。

## 初步假设

- 与其用一棵单线分叉的宗派树，不如同时使用“历史传播路线”“思想谱系”“戒律与组织传承”“修行系统”四张相互交叠的地图。
- 佛教的各部分共同服务于从苦及其成因走向解脱的目标，但不同历史传统对解脱主体、理想人格、经典权威和修行方法给出了不同答案。
- 现代学科分类有助于比较，却可能把业、轮回、仪式、禅修等强行心理学化或哲学化，需要保留佛教自身概念体系作为第二套坐标。

## 初步分析维度

1. 宇宙论与神话叙事。
2. 哲学：存在论、认识论、语言与逻辑。
3. 心理与心识理论。
4. 解脱论与修行技术。
5. 伦理、戒律与生活方式。
6. 仪式、崇拜与物质文化。
7. 僧团、传承与制度组织。
8. 社会、经济与政治关系。
9. 文献、语言、翻译与诠释传统。
10. 日常信仰、民间融合与身份认同。

## 待研究问题

- 历史佛陀及早期教法中哪些内容较有跨文本支持，哪些主要来自后世传记？
- 早期僧团分化、部派佛教和上座部之间应如何准确表述，避免把现存上座部直接等同于全部“原始佛教”？
- 大乘是怎样由多种文本、信仰与修行网络逐渐形成的？
- 密教与既有大乘、地方宗教及政治权力如何结合？
- 汉传、藏传和南传内部各自有哪些不能被“三大传统”标签覆盖的差异？
- 现代主义、民族国家、殖民主义、全球传播和世俗正念怎样改变了佛教？
