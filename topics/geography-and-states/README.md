# 地理对国家的影响

## 核心问题

地理通过哪些机制影响国家的形成、制度、经济、安全与长期发展？技术进步会削弱还是改变这些影响？

## 分析维度

- 农业条件、资源禀赋与人口承载。
- 山脉、平原、河流、海岸线与政治整合。
- 贸易通道、运输成本与城市网络。
- 边疆形态、防御成本与军事技术。
- 气候变化、灾害与疾病环境。

## 待讨论

- 地理约束与地理决定论的边界在哪里？
- 相似地理条件为何会产生不同制度和发展路径？
- 铁路、航空、互联网等技术如何重新定义距离？
