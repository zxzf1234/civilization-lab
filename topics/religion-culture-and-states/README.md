# 宗教、文化对国家的影响

## 核心问题

宗教和文化如何影响国家合法性、制度选择、社会合作、经济行为与对外关系？国家又如何反过来塑造宗教和文化？

## 分析维度

- 合法性、权威与政治仪式。
- 群体认同、社会信任与冲突边界。
- 伦理观念、经济行为与教育传统。
- 宗教组织、世俗权力与公共服务。
- 国家建构、语言政策与文化整合。
