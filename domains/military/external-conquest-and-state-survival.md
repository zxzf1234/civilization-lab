# 外部征服、力量不对称与国家存续

## 一句话定义

在允许领土兼并的国际环境中，如果一国与潜在征服者之间存在长期、显著的有效战争规模差距，又缺少能够提高征服成本的地理、联盟或制度保护，其被消灭、兼并或降为附庸的风险会上升。

## 机制或主要内容

国土面积不是决定性变量。这里的**有效战争规模**包括：

- 能够实际动员的人口和财政，而非账面资源；
- 军事组织、技术、指挥和后勤能力；
- 战略纵深和补充战争损失的能力；
- 联盟、缓冲国和外部援助；
- 吸收被征服地区人员、技术和资源的能力。

基本机制是：

```text
长期力量不对称
＋ 缺少可靠外援、地理屏障或国际保护
→ 强国预期征服收益高于成本
→ 弱国难以补充损失或阻止对手持续增强
→ 战败、附庸化、强制兼并或政权灭亡
```

扩张帝国还可能形成累积优势：

```text
征服一地
→ 获得人口、税收、军队、工匠和技术
→ 补足原有军事短板
→ 提高下一轮征服能力
```

蒙古—元征服南宋体现了这种过程：蒙古不只依靠草原骑兵，还逐步吸收北方农业区资源、攻城技术、汉人军队与水军能力。

## 适用条件与边界

这一机制在以下条件下更可能成立：

- 征服和领土兼并被视为正常或可接受行为；
- 强国与弱国地理相邻，军事力量能够到达；
- 占领成本低于领土、税收、安全或声望收益；
- 弱国没有可靠的强国保护者；
- 双方的力量差距能够持续，而非仅是短期战役优势。

这一机制不等于“小国必亡”。山地、海洋、气候、漫长补给线、全民动员、外交结盟和强国间制衡，都可能使小国成功存续。强国也可能认为附庸、纳贡或间接控制比正式吞并更合算。

古代与现代需要分开研究。现代的领土完整规范、国际承认、集体安全、威慑与占领成本，可能显著降低小国被直接兼并的概率；国家规模对存续的作用因此受国际体系调节。

## 证据与案例

| 案例 | 初步判断 | 说明 |
|---|---|---|
| 蒙古—元灭南宋 | 外力主导 | 南宋是大型国家，但面对具有更大资源池和持续吸收能力的征服帝国 |
| 金攻北宋与靖康之变 | 内外结合、外力触发 | 金军是直接力量，北宋改变均势和内部军政失误显著进入因果链；宋政权随后南迁重建 |
| 格拉纳达王国灭亡 | 待检验；可能为内外结合、偏外力 | 小国长期面对更强的卡斯蒂利亚—阿拉贡，同时存在王室内斗 |
| 晚期拜占庭灭亡 | 待检验；可能为内外结合、偏外力 | 昔日大帝国长期收缩后成为被奥斯曼包围的残余政权 |
| 琉球王国被日本兼并 | 外力主导候选 | 极端力量差距下经政治、外交和军事压力被撤销，而非大战摧毁 |
| 大理国被蒙古征服 | 外力主导候选 | 需要继续核实内部政治及蒙古征服过程 |

## 反例与争议

- 越南抵抗蒙古、日本抵抗蒙古等案例说明，总体更强不等于在特定战场必然获胜。
- 阿兹特克和印加看似被少量西班牙人征服，但土著盟友、内部政治和疫病都是关键因素，不能简单归为纯外力主导。
- “被外敌攻灭”只说明灭亡的执行者来自外部，不自动说明外力是最深层或最主要原因。
- 小国在史料中可能因被兼并而失去独立叙事，幸存的小国又可能形成选择偏差；跨案例统计必须统一“国家”和“灭亡”的定义。
