# 领域知识

这里沉淀能够被多个议题反复引用的知识。每篇笔记尽量只讲清一个概念、机制、理论或争论。

## 领域

- [政治](politics/README.md)：权力、制度、国家能力、合法性与治理。
- [经济](economics/README.md)：生产、分配、贸易、财政、金融与增长。
- [军事](military/README.md)：战争、战略、组织、动员、后勤与军政关系。
- [文化](culture/README.md)：价值观、规范、身份、语言、宗教与哲学。
- [地理](geography/README.md)：区位、地形、气候、资源与交通。
- [历史](history/README.md)：历史方法、时期、案例与长期演变。

领域不是互斥标签。一篇笔记选择一个主要归属，再链接到相关领域和议题即可。
