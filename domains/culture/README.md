# 文化

文化领域包含宗教与哲学，但讨论重点不局限于思想文本，也包括观念如何通过组织、仪式、教育和日常实践影响社会。

## 子领域

- [宗教](religion/README.md)：信仰、组织、伦理、仪式及其社会作用。
- [哲学](philosophy/README.md)：世界观、知识论、伦理与政治哲学。

## 关注的问题

- 价值观、规范和身份如何形成并传播？
- 文化如何影响合作、冲突、创新和制度？
- 文化是原因、结果，还是与其他因素共同演化？
- 文化变迁为何有时缓慢、有时突然？
- 宗教和哲学如何塑造合法性、伦理与社会秩序？
