# 案例研究

这里记录具体国家、文明、事件、时期以及跨案例比较，用现实过程检验议题中的解释和领域中的理论。

案例笔记主要回答：

- 发生了什么，关键时间顺序是什么？
- 当时有哪些政治、经济、军事、文化和地理条件？
- 哪些因素是长期条件，哪些是触发事件？
- 不同解释分别能说明什么，又遗漏了什么？
- 这个案例能够支持或反驳哪些更一般的判断？

案例不是简单的历史叙述。应尽量区分事实、来源观点和自己的解释，并链接到相关议题、领域知识与资料卡片。

新建案例时使用 [`案例模板`](../templates/case-note.md)。案例数量增加后，再按 `states/`、`civilizations/`、`events/` 和 `comparative/` 等类型建立子目录。
