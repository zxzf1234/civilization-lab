# 部派佛教与早期体系化

## 研究范围

本文承接[历史佛陀与早期佛教](historical-buddha-and-early-buddhism.md)，研究佛陀去世后的共同传统如何在地域扩张、口传分化、戒律制度化和教义解释中逐渐形成多个部派，并重点考察阿育王时代、佛塔与寺院网络、阿毗达磨体系化，以及大乘运动出现前后的过渡。

时间大致从公元前3世纪延伸到公元1世纪前后。这个界限只是研究工具：

- 僧团分化可能早于阿育王，也可能在不同地区以不同速度发生。
- 说一切有部、上座部等传统的成熟延续到公元后数世纪。
- 大乘文献可能从公元前1世纪前后开始出现，却没有立刻取代部派佛教。

## 核心问题

- 一个没有中央教会的僧团，为什么会形成多种戒律、经典和思想传承？
- “十八部”在多大程度上反映真实组织，还是后世整理出来的谱系？
- 阿育王的帝国支持如何改变佛教，同时又有哪些作用被后世放大？
- 阿毗达磨为什么出现，它解决了早期佛教留下的哪些问题？
- 佛教如何由游行修行共同体发展为拥有佛塔、寺院、财产和跨地域网络的宗教？
- 大乘是从部派佛教之外另起炉灶，还是在既有僧团内部逐渐形成？

## 一、概念界定与材料限制

### 1. “部派佛教”是什么

“部派佛教”指佛陀去世后形成的多个尼迦耶或教学、戒律和师承共同体。它们通常共同承认佛陀、解脱道路、僧团戒律及大量早期经教，却在下列问题上出现差异：

- 使用哪一种戒律传承；
- 承认哪些经文和阿毗达磨文本；
- 怎样解释无我、业、时间和因果；
- 怎样理解阿罗汉与佛陀；
- 怎样组织僧团及处理地方习惯；
- 与哪些语言、地区、寺院和赞助网络相联系。

它们不是现代政党，也不完全像基督教中互不共融的教会。一个部派名称有时表示受戒共同体，有时表示思想立场，有时只是后世论书中的分类标签。

### 2. 为什么不使用“小乘佛教”作为中性名称

“小乘”（Hīnayāna）是部分大乘文献用于批评被认为目标较低或道路有限者的称呼，不是早期各部派共同认可的自称。它也不能与“上座部”画等号：

```text
部派佛教 ≠ 小乘佛教 ≠ 现代上座部佛教
```

本文在描述历史共同体时使用具体名称或“早期部派”，只在分析大乘文献的论争语言时使用“小乘”。

### 3. “十八部”不是准确人口普查

不同佛教传统保存的部派名单、分裂顺序和争议原因彼此冲突，总数也并不总是十八。“十八”更像对多种分支的传统概括。较稳妥的判断是：佛教在印度不同地区确实形成了多个教团和思想传统，但无法重建一棵完全可靠、逐年分叉的宗派树。[斯坦福哲学百科“阿毗达磨”条目](https://plato.stanford.edu/entries/abhidharma/)

### 4. 主要材料及其偏差

| 材料 | 能说明什么 | 主要限制 |
|---|---|---|
| 各部派律藏 | 僧团规则、结集与分裂记忆 | 经后世编辑，常把本派制度投射到佛陀时代 |
| 巴利编年史 | 上座部、阿育王和斯里兰卡传播传统 | 成书晚，服务于大寺派的正统叙事 |
| 阿毗达磨与论争文本 | 各派哲学立场和分类系统 | 常以对手概括对方，可能简化或歪曲 |
| 阿育王铭文 | 公元前3世纪国家政策、佛教圣地和僧团存在 | 不能证明后世佛教史书的全部叙事 |
| 佛塔、寺院、造像及捐赠铭文 | 实际赞助者、地域网络和宗教实践 | 很少直接解释复杂教义或部派身份 |
| 汉译、藏译和残存梵语文献 | 保存印度本土失传材料 | 翻译年代晚，术语和文本层次复杂 |

因此，传统史书中的宗派谱系应与铭文、考古和跨部派文本比较使用。

## 二、从共同僧团到多个部派

### 1. 分化并不等于信仰全面破裂

早期僧团以地方共同体为基本行动单位，通过布萨、诵戒、受戒和羯磨维持秩序。不存在一个能够给全印度僧团下达日常命令的永久中央机构。

当佛教向不同地区传播时，出现如下机制：

```text
传播距离扩大
→ 地方僧团独立运作
→ 语言、戒律习惯和经文排序产生差异
→ 师承及寺院网络强化自己的版本
→ 差异经论书和正统叙事固定
→ 部派身份逐渐形成
```

这可能是长期累积，而不是某次会议后所有僧侣立即分为互相排斥的阵营。

### 2. 戒律分歧

传统把佛陀去世后约百年的毗舍离结集与“十事”争议联系起来，包括金钱、饮食和僧团程序等问题。不同律藏对事件、参与者和后果的叙述不完全一致。

戒律分歧的重要性在于，受戒谱系决定谁能与谁共同举行正式僧团仪式。相比抽象哲学差异，戒律和羯磨程序更可能形成可观察的制度边界。

但不能因此断定最初分裂完全由“十事”造成；后世还把大天五事等教义争议追溯为分裂原因。现有材料难以确定单一导火索。

### 3. 地域、语言与师承

佛教传播到西北印度、恒河流域、德干、南印度和斯里兰卡以后，不同共同体使用多种中古印度语言，选择不同经典组合，并与不同王权、商路和施主群体交往。

部派名称本身也显示多种来源：

- 教义立场：如“说一切有部”；
- 权威来源：如“经量部”，即强调经；
- 创始或师承人物：如“犊子部”；
- 地域：如“雪山部”；
- 共同体自我理解：如“上座部”“大众部”。

这说明部派形成不能只用教义争论解释。[斯坦福哲学百科对部派名称和地域化的概述](https://plato.stanford.edu/entries/abhidharma/)

## 三、部派谱系：一张谨慎使用的地图

传统叙述往往把第一次主要分裂概括为：

```text
早期僧团
├── 上座部系（Sthavira）
│   ├── 说一切有部
│   ├── 犊子部及正量部等
│   ├── 分别说系诸传统
│   │   └── 斯里兰卡上座部
│   └── 其他分支与思想倾向
└── 大众部系（Mahāsāṃghika）
    ├── 一说部
    ├── 说出世部
    ├── 制多山诸部
    └── 其他地区分支
```

这张图只能表示传统上的大方向，不能视为已经由同时代记录验证的完整家谱。不同来源对分别说部、法藏部、化地部、饮光部和上座部之间的关系尤其有不同排列。

### 1. 上座部系不等于今天的南传上座部

“上座部系”是早期大类；现代斯里兰卡及东南亚上座部继承其中一支。说一切有部、法藏部等同样常被放在广义上座系谱中，却拥有不同的律藏和阿毗达磨。

今天汉传僧侣主要采用法藏部律，藏传僧侣采用根本说一切有部律，南传佛教采用巴利律。这说明早期部派虽然多数不再以完整宗派存在，其戒律遗产仍在当代佛教中延续。

### 2. 大众部与大乘不能画等号

大众部某些支系强调佛陀的超世间性质，对阿罗汉能力也可能采取较低评价，这些观念与后来部分大乘思想存在相似性。

但不能据此推出：

```text
大众部 = 大乘的唯一祖先
上座部系 = 大乘的敌对旧派
```

大乘材料和信仰可能出现在多个部派所属的寺院环境中。大众部只是其形成背景之一，而不是完整源头。[Encyclopedia.com 对大众部与大乘关系的谨慎概述](https://www.encyclopedia.com/environment/encyclopedias-almanacs-transcripts-and-maps/mahasamghika)

## 四、阿育王时代

### 1. 可以直接确认的内容

阿育王约于公元前3世纪统治孔雀帝国。他留下的石刻和柱铭是研究这一时期最重要的同时代资料。部分铭文显示：

- 他自称在家佛教徒，并逐渐接近僧团；
- 他尊敬佛、法、僧；
- 他访问并减免蓝毗尼的税赋；
- 他向僧团推荐若干教法文本；
- 他关心僧团分裂问题；
- 其公共“法”强调少杀生、节制、孝敬、善待臣民和尊重不同宗教群体。

这些证据足以确认佛教在当时已形成有经典、有僧团和有圣地的制度性宗教。[Romila Thapar 编译的阿育王敕令](https://projects.mcah.columbia.edu/indianart/pdf/asoka_thapar.pdf)

### 2. 阿育王的“法”不完全等于佛教教义

多数面向全体臣民的敕令很少讲四圣谛、无我或涅槃，而侧重公共伦理和治理。可以暂时区分：

| 层面 | 主要内容 |
|---|---|
| 阿育王的私人佛教身份 | 皈依、接近僧团、尊敬佛法僧 |
| 面向帝国的公共“法” | 不杀、节制、孝敬、宽容、官员责任 |
| 对僧团的政策 | 保护、劝学、处理或威慑分裂 |

因此，阿育王既是佛教护持者，也是试图为多宗教帝国建立公共伦理的统治者。

### 3. 后世传统可能放大了什么

后世佛教文献称阿育王召集第三次结集、清除僧团异见、派出多路传教使团，并建造八万四千佛塔。不同传统对第三次结集的记载并不一致，八万四千也明显具有象征性。

较稳妥的判断是：阿育王的支持显著提高了佛教的物质规模、政治可见度和跨地区联系；但不能证明所有传播路线均由一次中央派遣造成。

### 4. 国家支持的双重效应

```text
王权支持
├── 提供建筑、交通、铭文和安全资源
├── 扩大圣地及僧团网络
├── 提高佛教的公共声望
└── 同时使国家获得介入僧团边界和纪律的能力
```

佛教与国家之间从一开始就不是单向控制关系：僧团能为统治者提供道德声望，王权也能塑造僧团秩序。

## 五、佛教传播到斯里兰卡

斯里兰卡编年史称，阿育王之子摩哂陀把佛教传给天爱帝须王，阿育王之女僧伽蜜多随后带来菩提树枝并建立比丘尼传承。

需要区分三种判断：

- 公元前数世纪，佛教从印度传播至斯里兰卡，可信度较高。
- 王权支持、寺院建立和跨海联系发挥重要作用，也较可信。
- 具体人物关系、对话、日期和由中央组织的一次性传播过程，主要依赖数百年后成书的编年史。

斯里兰卡逐渐形成以大寺为中心的上座部传统，但也出现无畏山寺等竞争性寺院。后来所谓“上座部”的统一形象，是长期竞争、编纂与改革的结果。

## 六、佛塔、舍利、朝圣与物质文化

### 1. 佛塔使去世的佛陀继续在场

佛塔最初与遗骨和纪念性坟冢相关。佛教把佛陀、重要弟子和高僧舍利安置其中，使其成为礼拜、绕行、布施和朝圣的中心。

舍利并非只被当作纪念物。信徒可把佛塔理解为觉者力量的真实在场，因此修建、供养或绕行佛塔能够积累功德。[大都会艺术博物馆关于早期印度佛塔与舍利崇拜的说明](https://www.metmuseum.org/es/essays/buddhism-and-buddhist-art)

### 2. 桑奇显示了什么

桑奇建筑群从阿育王时代起发展，后续王朝、地方精英、商人、行会、僧尼和普通信徒持续扩建。现存建筑和铭文显示，佛教物质文化不是只有皇帝单独建设，而是多层赞助网络共同形成。[联合国教科文组织“桑奇佛教遗址”](https://whc.unesco.org/en/list/524)

桑奇等早期艺术常以法轮、菩提树、足迹、空座和佛塔象征佛陀，而非直接塑造人形佛像。“无佛像”不代表没有强烈崇拜，反而说明象征物、舍利和地点能够承载佛陀的临在。

### 3. 地方神灵的整合

早期佛塔艺术大量出现夜叉、夜叉女、龙、树神和丰饶象征。这不宜简单称为佛教被“民间迷信污染”。更可能的传播机制是：

```text
地方神灵与圣地原已受到敬畏
→ 佛教叙事把它们解释为护法、归依者或轮回众生
→ 旧有地点和象征进入佛教功德体系
→ 佛教获得地方可理解性
```

## 七、寺院化与僧团经济

### 1. 从游行到常住

佛陀时代已经有雨安居和施主提供住所的传统。随着土地、建筑、蓄水设施和佛塔群积累，部分僧团日益常住化。寺院成为：

- 修行和诵经场所；
- 受戒与教育中心；
- 保存经典和物品的机构；
- 施主积累功德的对象；
- 朝圣、住宿和地方交流节点。

### 2. 僧侣贫穷与寺院富有的张力

个人出家者受到不蓄财等规范约束，但僧团作为集体可以接受建筑、园林、衣药和长期供养。这产生了一个持续存在的制度张力：

```text
个人无所有的修行理想
≠
维持大型僧团所需的集体资源
```

这不必自动被解释为“腐败”。真正需要研究的是资源由谁控制、如何记账、是否影响教义和僧团权力。

### 3. 谁在供养佛教

捐赠铭文显示，支持者不限于国王，也包括：

- 王室女性和地方精英；
- 商人、银行家与行会成员；
- 僧侣和比丘尼；
- 家庭成员和普通信众。

布施一方面解决寺院物质需求，另一方面把财富转换为功德、声望和亲属纪念。它不能被简化为购买宗教服务，也不能只用无私善行解释。

## 八、口传、书写与经典形成

### 1. 多种经典而非一部统一圣经

随着部派形成，各传统拥有部分重合但不完全相同的：

- 经藏或阿含；
- 律藏；
- 阿毗达磨；
- 本生、譬喻、传记和注释材料。

经藏之间仍保存大量共同结构，说明其核心材料早于部派定型；阿毗达磨和部分律藏差异则更能显示各派发展。[早期教法口传与部派经典形成概述](https://www.cambridge.org/core/books/abs/reconstructing-early-buddhism/sangha-and-the-oral-transmission/57CB82F33AB60B2412E0AA87E1DCE693)

### 2. 从口传到书写

阿育王时代婆罗米文开始广泛用于公共铭文，但佛教经典仍长期依靠口传。斯里兰卡传统称公元前1世纪因战争、饥荒及传承危机而将巴利三藏写下。

书写并未立刻取代背诵。文本仍通过诵读、讲解和记忆获得权威；手稿脆弱，口传与书写长期共存。

### 3. 经典边界是一种权力问题

“什么是佛说”决定哪些教义和修行可以获得最高权威。不同共同体可能以以下标准认证文本：

- 是否符合已有的法与律；
- 是否由可信师承传来；
- 是否得到僧团共同认可；
- 是否被认为能够导向解脱；
- 是否可解释为佛陀针对不同对象的方便说法。

这些机制后来也为大乘经典声称“佛说”提供了诠释空间。

## 九、阿毗达磨：从教法列表到系统哲学

### 1. 阿毗达磨在做什么

早期经文使用五蕴、十二处、十八界、七觉支、八正道等法目。阿毗达磨把这些列表重新整理，试图建立一张无矛盾、可用于教学和修行的经验地图。

它主要处理：

- 哪些现象是基本的“法”；
- 每种心如何与感觉、意志和认知因素共同生起；
- 因果有多少类型；
- 善、不善和中性心理如何区分；
- 修行者经过哪些阶段；
- 如果没有恒常自我，经验与业果如何连续。

阿毗达磨不是单纯心理学。它同时是：

```text
经典解释学
+ 经验分类学
+ 存在论
+ 因果理论
+ 伦理心理学
+ 禅修地图
```

### 2. 现存两套完整阿毗达磨藏

现存完整经典阿毗达磨主要属于：

- 巴利上座部，共七部论；
- 说一切有部，共七部论，主要由汉译保存。

两套系统有共同问题意识，但文本、分类和答案并不相同。这本身说明阿毗达磨不是佛陀时代一次完成的统一第三藏，而是在各派内部逐步发展。[剑桥《印度佛教哲学》阿毗达磨概述](https://www.cambridge.org/core/books/abs/indian-buddhist-philosophy/abhidharma/4563F47F592510EDA21FD2DB452FDBAE)

### 3. 从世俗语言到究竟分析

阿毗达磨常区分：

- 日常约定层面的“人、车、房屋”；
- 分析层面的色、受、识及其他法。

这样可以说“某人造业受报”，同时坚持没有永久自我。但它也带来新问题：如果基本法被当作真正存在的单位，佛教会不会在否定“人我”之后，又建立“法我”？这个问题后来成为中观批评的重要背景。

## 十、代表性部派与核心争论

以下不是完整名单，而是选择能够显示思想结构的代表。

### 1. 说一切有部：三世与因果连续

说一切有部主要在北印度和西北印度发展，其名称与“过去、现在、未来之法皆以某种意义存在”的立场有关。

它面对的问题是：

```text
若过去已经完全不存在
→ 过去行为如何在未来产生果？

若未来完全不存在
→ 修行趋向未来结果如何成立？
```

其答案不是说三世事物都以相同方式活动，而是区分法的存在与当下作用。后来毗婆沙师发展了复杂解释。

主要反对意见是：这会不会削弱佛教的无常论，把过去和未来重新实体化？

### 2. 经量部／譬喻师：强调经与当下因果

“经量部”通常指对说一切有部正统阿毗达磨持批评态度、强调经教权威的思想倾向。它是否在早期就是边界清楚的独立受戒部派，仍有争议。

其后来的典型主张包括：

- 只有当下法具有现实作用；
- 过去行为通过相续中的潜在能力产生未来果；
- 认知未必直接接触已经消逝的外境，而通过表象把握对象。

许多成熟理论见于更晚文献，不能全部倒推至本文时间范围。[斯坦福哲学百科关于说一切有部与经量部的讨论](https://plato.stanford.edu/entries/abhidharma/)

### 3. 犊子部／补特伽罗论者：谁在轮回

无我论产生一个持续难题：

```text
造业者与受报者若完全相同
→ 容易落入恒常自我

若完全不同
→ 道德责任和修行连续如何成立？
```

补特伽罗论者提出“补特伽罗”或“人”，认为它不能说与五蕴完全相同，也不能说完全不同。这不是简单恢复婆罗门式永恒灵魂，而是试图保护人格与业报连续性。

其他佛教派别批评这一概念不可说明，并认为它暗中恢复自我实体。该争论显示，“无我”从来不是没有困难的口号。

### 4. 大众部相关传统：佛陀与阿罗汉

部分大众部材料强调：

- 佛陀具有超世间性质；
- 佛陀的知识和能力远超普通修行者；
- 阿罗汉仍可能存在某些局限。

这些思想扩大了佛陀与弟子的距离，为后来的多佛、菩萨和超越性佛身观提供了可利用的语言，但不能证明大乘完全由大众部产生。

### 5. 斯里兰卡上座部：分别论与经典正统

上座部传统把自身与分别说联系起来，保存了巴利三藏，并以《论事》等文本记录对其他部派观点的反驳。

这一传统后来在斯里兰卡进一步形成大寺、无畏山寺等寺院竞争。今天所谓上座部的经典和注释体系，是早期印度传统、斯里兰卡编纂以及更晚注释家共同塑造的，不能全部归入阿育王时代。

## 十一、哲学层面

### 1. 早期共同教法变成争论对象

佛陀时代用来指导修行的概念，在部派时期逐渐被追问其严格含义：

| 早期教法 | 体系化问题 |
|---|---|
| 无我 | 承担业果和获得解脱者是谁？ |
| 无常 | 法持续多久，变化是否发生在瞬间？ |
| 缘起 | 条件关系有多少种，跨时间因果如何成立？ |
| 五蕴 | 五蕴是教学分类，还是真实存在的基本单位？ |
| 涅槃 | 涅槃只是烦恼停止，还是一种无为法？ |
| 佛陀 | 佛陀与阿罗汉在智慧、能力和存在方式上有何差别？ |

### 2. 分析带来的收益与风险

收益包括概念精确、教学可复制、争论可以检验、修行阶段清楚。风险则是：原本用于解除执著的分类，可能变成关于世界基本实体的繁复理论。

后来的大乘哲学既继承阿毗达磨问题，又批评其可能把“法”实体化。

## 十二、心理与心识层面

阿毗达磨把心理经验分解为心与多种心所，例如感受、辨认、意志、注意、贪、嗔、信、念和慧。不同学派的数量和分类不同。

其主要特点是：

- 心不是一个不变容器，而是一连串条件性事件；
- 每个心念带有伦理性质和因果后果；
- 烦恼可以依对象、条件和对治方法分类；
- 禅定状态可以按心理因素的有无分析；
- 修行是改变心流结构，而不是释放一个永恒灵魂。

与现代心理学比较时需要注意：阿毗达磨的观察服务于业、轮回和涅槃框架，也依赖内省与修行传统，不采用现代实验科学的方法。

## 十三、解脱论与修行体系

### 1. 道路逐渐阶位化

部派传统把修行道路组织为更细的阶段，例如资粮、准备、见道、修道及无学等不同框架。阿罗汉类型、禅定层级、烦恼断除顺序也得到系统区分。

这种阶位化具有双重效果：

- 帮助教师诊断修行进展；
- 也可能使解脱显得遥远、专业化，并增强经论专家的权威。

### 2. 阿罗汉与佛陀

各派普遍承认阿罗汉已从轮回解脱，但对其是否仍会无知、受他人提示或具有局限存在争议。佛陀与阿罗汉究竟只是“自行发现道路”与“跟随道路”的区别，还是存在知识和本体层面的巨大差距，也成为大乘兴起前的重要问题。

### 3. 菩萨道路并非大乘凭空发明

早期部派传统已经承认释迦牟尼在过去世作为菩萨积累功德，未来弥勒也会成佛。差别主要在于：

- 部派佛教通常把成佛视为极少数人的漫长道路；
- 大乘逐渐把发菩提心和成佛理想推广为其核心规范。

## 十四、伦理与戒律层面

### 1. 戒律成为部派的制度骨架

教义差异未必阻止共同生活，但不同戒律和受戒传统会影响僧团共住与正式仪式。戒律因此兼有：

- 修行训练；
- 共同体宪章；
- 身份认证；
- 财产和冲突处理规则；
- 对外维持声誉的机制。

### 2. 戒律适应与“纯洁”争论

僧团进入不同气候、饮食和政治环境后，必然面对规则解释。严格与宽松并不总等于保守与腐败；有时两方是在权衡：

```text
保持共同标准
↔
适应地方生存条件
```

后世宗派史经常把本派描述为守护原始戒律，把对手描写为放逸者，需要警惕胜利者叙事。

## 十五、仪式、神话与日常信仰

### 1. 功德成为连接出家与在家的关键语言

在家信徒通过布施、建塔、供灯、供花、守戒和听法积累功德，并可把功德回向亲属或众生。僧团则成为“福田”。

功德体系把个人来世、家庭纪念、公共建筑和僧团经济连接起来，是佛教社会扩张的核心机制之一。

### 2. 本生故事与佛陀神圣化

本生故事叙述佛陀过去世以动物、国王、修行者等身份积累布施、忍辱和智慧。这些故事：

- 解释佛果需要长时积累；
- 提供适合大众传播的伦理范例；
- 把地方故事纳入佛教历史；
- 强化佛陀超越单一人生的神圣身份。

### 3. 佛像出现以前的佛陀临在

早期艺术常通过空座、法轮、菩提树、足迹和佛塔表现佛陀。过去常称其为“无像时期”，但这不应理解为拒绝形象或缺乏崇拜。象征物、故事浮雕和舍利已经构成丰富的视觉宗教。

## 十六、组织、知识与权威

### 1. 三种权威来源

部派佛教逐渐形成相互竞争又彼此结合的权威：

1. **经典权威**：什么被承认为佛说。
2. **戒律权威**：谁拥有有效受戒及举行羯磨的资格。
3. **解释权威**：谁能系统说明经典、辩论和指导修行。

阿毗达磨专家、持律者、诵经者和禅修者可能形成不同专业群体。

### 2. 正统不只由教义决定

某一传统能够延续，取决于：

- 是否有稳定寺院和施主；
- 是否拥有连续受戒谱系；
- 是否保存和复制经典；
- 是否得到王权或地方势力保护；
- 是否能培养教师和翻译者；
- 是否在迁徙、战争和饥荒中幸存。

今天只有上座部作为早期部派名称继续存在，不证明它在古代辩论中必然“获胜”；文献保存、地理位置和政治历史同样重要。

## 十七、大乘出现前的过渡

### 1. 大乘最初可能不是独立受戒部派

现有研究通常不把早期大乘理解为某次结集后建立的新教会。早期大乘修行者可能仍依既有部派律受戒，生活在同一寺院，只是在经典、誓愿和修行目标上形成新的网络。

一种候选机制是：

```text
既有菩萨与过去佛观念
+ 佛塔、舍利和多佛信仰
+ 对佛陀超越性的强化
+ 新经典及其诵持团体
+ 对普遍成佛道路的追求
→ 多种早期大乘运动逐渐出现
```

斯坦福哲学百科的佛教伦理条目也概述了一种学术观点：早期大乘可能处于既有佛教制度之内，最初主要由共同选择成佛道路的修行者构成。[“印度佛教伦理”条目](https://plato.stanford.edu/entries/ethics-indian-buddhism/)

### 2. 不能把大乘只解释成在家人反抗僧侣

早期大乘经典高度重视出家修行，也有大量僧侣作者、翻译者和保存者。虽然部分文本提高在家菩萨地位，但“大乘是在家人的民主运动”不足以解释其整体。

### 3. 也不能把大乘只解释成佛塔崇拜

佛塔和舍利为佛陀神圣临在、多佛观及功德实践提供环境，但部派佛教同样崇拜佛塔。仅靠佛塔无法解释般若空性、新佛国、菩萨誓愿和新经典权威。

## 十八、部派佛教为何繁荣：候选解释

### 解释一：分散制度增强了适应性

```text
没有单一中央教会
→ 地方僧团可适应语言、气候和赞助结构
→ 传播成本降低
→ 同时产生经典和戒律差异
```

### 解释二：寺院把宗教变成可积累的机构

建筑、土地使用、手稿、舍利和师承能够跨越个人寿命，佛教不再完全依赖游行教师的个人魅力。

### 解释三：功德经济连接多种社会群体

国王、商人、妇女、行会、僧尼和普通家庭都可通过不同规模的捐赠参与佛教，而不必全体出家或掌握复杂哲学。

### 解释四：阿毗达磨提高了知识竞争力

系统化使佛教能够培养专家、回应内部矛盾并与婆罗门、耆那和其他学派辩论。

### 解释五：帝国与贸易网络扩大传播

孔雀帝国及后继政权、南北商路和西北交通促进人员、文本、艺术和资金流动。但传播不是国家单向规划的结果。

## 十九、反例与替代解释

### 1. 分化是否主要来自教义争论

传统论书倾向用观点差异定义各派，但真实分化可能更常由戒律、地域、寺院和师承造成。教义差异也可能是组织分开以后才被系统放大。

### 2. 阿育王是否“使佛教成为世界宗教”

阿育王显然扩大了佛教的公共规模，但佛教此前已经传播，帝国解体后佛教也依靠非国家网络继续成长。把成功完全归功于阿育王，会忽略僧团制度、商路和地方施主。

### 3. 寺院财富是否意味着早期理想衰落

资源积累可能产生腐败和权力差距，也可能是保存经典、供养病者、教育僧侣和维持跨地区网络的条件。需要按具体寺院和时期判断，不能用“纯洁—堕落”单线模型解释。

### 4. 阿毗达磨是忠实解释还是教义创新

各派都可能声称阿毗达磨是佛陀深层教法；历史研究则显示现存体系有长期发展。它既保存早期分析，也加入了新分类和新论证，两者并不互相排斥。

### 5. 大乘是否必然从部派矛盾中出现

大乘利用了佛陀观、菩萨道和经典权威等既有问题，但其形成还可能依赖新的宗教体验、文本社群、礼拜对象和跨地区文化，不能从某一部派学说线性推导。

## 二十、阶段性结论

### 当前判断

部派佛教不是统一佛教突然破裂后的残片，而是佛教在广阔地域中制度化、专业化和地方化的结果。僧团依靠戒律、口传、寺院、布施和受戒谱系复制自身；阿毗达磨则把早期修行语言发展为系统哲学与心理分析。

阿育王的支持放大了这一过程，却没有单独创造它。大乘也不是简单取代部派佛教，而是在部派寺院与更广泛的佛教物质、文本和信仰环境中逐渐出现。

### 作用机制

```text
跨地域传播
→ 地方僧团、语言和师承差异
→ 戒律及经典版本固定
→ 部派身份形成

布施与王权支持
→ 佛塔、寺院和教育资源积累
→ 僧团能够跨代延续

教法解释压力
→ 阿毗达磨系统化
→ 新的哲学问题与争论
→ 为大乘思想提供继承和批评对象
```

### 适用范围

该判断主要适用于公元前3世纪至公元1世纪前后的南亚佛教。部分思想和制度发展延续至公元后数世纪，本文仅处理其形成阶段。

### 主要不确定性

- 第一次主要分裂的时间、地点和原因无法确定。
- 各部派谱系主要来自互相冲突的后世记录。
- 早期大乘社群与具体部派、寺院之间的对应关系证据有限。
- 文本规范与僧侣、信众实际生活之间仍有距离。

### 信心水平

**中等。**多部派存在、阿毗达磨体系差异、阿育王护持和佛塔寺院扩张有较强文本及考古依据；精确谱系、结集叙事和各派最早立场的可信度较低。

## 二十一、待验证问题

- 各律藏对毗舍离结集和首次分裂的叙述具体有哪些差异？
- “分别说部”是一个真实统一组织，还是后世谱系分类？
- 补特伽罗论者留下的原始文本能否修正对手对其观点的描述？
- 捐赠铭文显示女性、商人、僧尼和王室各自承担多大比例的供养？
- 阿育王的僧团分裂敕令在不同地点文字是否一致，应怎样解释？
- 巴利和说一切有部阿毗达磨的共同层次与独立创新分别是什么？
- 最早般若类文本的年代、地域和所属寺院环境如何判断？
