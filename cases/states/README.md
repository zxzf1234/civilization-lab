# 国家纵向兴衰档案

本目录按国家建立长期档案。每个文件以“国家—时期”为分析单位，按该国自身历史分期记录生产能力、国家能力、财政韧性、居民福祉、政治纠错、未来能力和相对国力。

阶段判断必须同时包含：

- **纵向比较**：相对于本国上一时期是改善、停滞还是恶化；
- **横向比较**：相对于同期合理对照国是追赶、同步还是落后；
- **判断类型**：兴盛、结构转型、高位平台、相对衰落、绝对衰落、危机、政权崩溃或国家解体；
- **信心与争议**：资料质量、替代解释和不能解释的事实。
