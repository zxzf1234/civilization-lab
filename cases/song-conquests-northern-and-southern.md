# 北宋与南宋灭亡的内外因素

## 研究范围

比较金攻北宋与蒙古—元灭南宋，判断两次重大断裂分别更接近外力主导、内崩主导还是内外结合。北宋和南宋是同一宋朝的两个阶段：1127年是原中央朝廷崩溃、北方领土丧失和国家中心南迁，1279年才是赵宋政权最终灭亡。这里研究的政权变化不等同于中国社会、文化或国家制度整体灭亡。

## 核心问题

- 两宋在外敌进攻前是否已经接近自行崩溃？
- 内部问题是一般性弱点，还是直接决定战争失败的关键机制？
- 征服者的异常强大是否足以解释结果？

## 关键事实与时间线

### 北宋

- **事实**：北宋长期维持规模很大的常备军，并能取得较高财政收入，但边防开支沉重；军费在一些估算中占国家预算极高比例。
- **事实**：宋辽澶渊体系维持了一个多世纪的相对和平。12世纪初北宋联金攻辽，原有均势和北部防御环境被破坏。
- **事实**：金灭辽后转而攻宋，1127年攻陷开封，俘获徽、钦二帝，北宋政权结束；宋宗室随后在南方重建政权。
- **来源观点**：近期研究强调，北宋主动改变联盟与边疆安排、失败的进攻以及战略纵深遭到破坏，都加速了开封陷落，而不能只归因于抽象的“重文轻武”。

### 南宋

- **事实**：南宋建立后长期维持行政、财政与社会秩序，并针对江淮和长江环境发展了不同于北宋的军队和水军体系。
- **事实**：南宋面对蒙古抵抗约半个世纪；蒙古早期难以突破淮河—长江防御，后来建立水军，并吸收熟悉攻城、水战和地方环境的人员。
- **事实**：蒙古已征服或控制广阔地区，能够调动跨区域资源。1276年临安降，1279年崖山之战后残余宋廷覆灭。
- **来源观点**：宋代军事制度研究认为，宋军更适合防御和内部安全；南宋长期抵抗本身不支持“完全没有军事能力”的简单叙事。

## 候选解释

### 北宋：内外结合，外力触发

暂不归为纯粹的外力主导型，理由是：

1. 金军的兴起与进攻是北宋在1127年灭亡的必要直接原因；没有金军攻宋，北宋没有证据显示会在同一时间自行瓦解。
2. 但北宋朝廷主动联金攻辽、误判新旧敌人的力量、进攻表现不佳并破坏既有防御安排，使内部决策直接进入了灭亡因果链。
3. 北宋并非财政已经完全枯竭或全国性统治已经先行解体，因此也不属于内崩主导型。

简化机制：

```text
强大的金兴起
＋ 北宋改变稳定的地区均势
＋ 战略判断、军队效能与首都防御失误
→ 金军迅速攻陷开封
→ 北宋中央政权灭亡
```

更准确的标签是：**内外结合型，外敌进攻是触发和执行灭亡的力量**。

### 南宋：外力主导，内部与战争过程因素辅助

暂归为外力主导型，理由是：

1. 蒙古进攻前，南宋仍能长期治理、征税和组织防御，没有显示其即将因内部崩溃而灭亡。
2. 蒙古是具有异常广泛动员能力的扩张帝国，征服范围远超宋境；南宋面对的不是普通边患。
3. 南宋抵抗时间很长，说明其失败不是内部国家机器先行突然崩溃的简单结果。
4. 蒙古在战争中学习水战和攻城、吸收降人与原有军队，逐步克服南宋的地理和水军优势。

简化机制：

```text
蒙古取得压倒性的跨区域资源与军事优势
→ 长期战争中适应南方攻城和水战
→ 逐步突破南宋防御体系
→ 领土、军队和朝廷相继丧失
→ 南宋灭亡
```

南宋的朝政、军队组织和用人问题仍需继续研究，但目前没有足够证据把它们提高为与蒙古力量同等的主导原因。

## 反例与争议

- 北宋覆灭后宋政权能迅速在南方重建，说明“北宋灭亡”不等于宋朝全部国家能力已经耗尽。
- 南宋长期抵抗蒙古，而蒙古在越南、日本等地的扩张并非全部成功；因此蒙古强大不是脱离地理、后勤和防御制度后必然获胜的充分条件。
- “经济发达但军事不行”过于粗略。需要进一步研究财政收入转化为有效军力的各环节，而不能把经济和军事直接对立。
- 降将、地方合作者和被征服地区资源究竟属于“南宋内部衰弱”还是“蒙古在战争中的能力增长”，需要明确分类。暂时将其视为双方互动产生的战争过程因素。

## 阶段性结论

- **当前判断**：北宋是内外结合型，南宋更接近外力主导型。
- **适用范围**：这里只判断两次政权灭亡的主导原因，不解释宋代长期相对军事弱势的全部来源。
- **主要不确定性**：北宋内部政治与军事失误应占多大权重；南宋后期内部问题对最后崩溃的贡献。
- **信心水平**：中等。直接战争过程较清楚，但内部因素的反事实权重仍需更多专题研究。
